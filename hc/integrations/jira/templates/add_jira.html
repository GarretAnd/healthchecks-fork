Jira

Jira is an issue and project tracking tool. This integration creates a Jira issue when a check goes down and closes it again when the check comes back up.

Setup Guide

In your Jira Cloud site, go to Account settings → Security → Create and manage API tokens and create an API token.

Note your Jira site URL (for example https://company.atlassian.net) and the project key where issues should be created.

Enter the details below. The Close transition is the name of the workflow transition that resolves an issue (commonly Done or Close Issue).
